# 🧮 Prime Calculator – Scientific Calculator App

> A modern, feature-rich Android calculator built with Java and XML, combining scientific calculations, calculation history, unit conversion, and real-time currency conversion.

---

## 📱 About the Project

**Prime Calculator** is an all-in-one Android calculation utility developed from scratch using **Java and XML**.

The application goes beyond basic arithmetic by combining:

* 🧮 Basic & scientific calculations
* 🕐 Calculation history
* ⚖️ Unit conversion
* 🎨 Modern dark-themed UI
* ✨ Interactive animations
* 🐛 Error handling and debugging

This project was also a hands-on learning experience in **Android development, UI/UX design, API integration, networking, debugging, and application optimization**.

---

# ✨ Features

## 🧮 Scientific Calculator

* ➕ Addition, subtraction, multiplication, and division
* 🔢 Decimal calculations
* 🧩 Parentheses
* 🔄 Positive/negative numbers
* 📐 Trigonometric functions
* 📊 Logarithmic functions
* √ Square root
* x² Square
* xʸ Powers
* π Pi

## 🕐 Calculation History

* 📜 Save previous calculations
* 🔍 View expressions and results
* 🗑️ Delete individual entries
* 🧹 Clear complete history

## ⚖️ Unit Converter

Supports multiple categories including:

* 📏 Length
* ⚖️ Mass
* 🌡️ Temperature
* 📐 Area

## 💱 Currency Converter

* 🌍 Multiple currencies
* 🔄 Dynamic conversion
